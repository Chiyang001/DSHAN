# 图片上传、引用和注释真机验证

日期：2026-10-12。设备：PKQ110，ADB USB 连接。使用覆盖安装的 Debug APK；保留原有应用数据。测试没有发送模型请求。

## 已验证

- 系统文件选择器能打开，选择 PNG 后返回 DSHAN，出现文件名及图片附件预览。
- 一次选择两张 PNG，两张附件均返回并出现预览（验证 ClipData 多选结果）。
- 取消选择后再次打开选择器正常。
- 长按测试文字，在系统选文菜单的“⋮”中找到“引用”和“写注释”。
- 点击“引用”后，选中文字以 `>` 引用格式追加到已有草稿。
- 点击“写注释”打开原生输入弹窗，填写 `DSHAN-note-001` 并点击“加入草稿”，原文和注释均追加，已有草稿保留。
- 通过实际 WebView 的编辑器粘贴处理验证中文原文和中文注释的草稿写入。
- 测试后移除全部测试附件、清空测试草稿，删除推送的两张临时图片和设备上的测试截图、界面转储；模型推理等级恢复为测试前的 High。

## 验证范围

验证覆盖 Android 文件选择与附件生成，以及引用、注释写入草稿。未向模型发送图片或文字，也未验证模型识图结果。测试选文使用临时测试段落，不使用用户会话内容。

选文功能入口可能位于系统菜单的“⋮”中，具体位置由手机系统决定。注释会作为文字随引用加入草稿，不是独立的文档批注存储。

Debug 构建允许 WebView 调试用于本地真机验证；非 Debug 构建关闭此入口。
