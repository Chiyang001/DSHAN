# 联动消息验收（2026-10-22）

版本：电脑插件 0.1.8；DSHAN 1.2.7（versionCode 10）。

## 使用

手机和电脑完成配对后，打开两端左侧的「联动消息」。可新建联动对话，或选择「加入已有对话」同步一段本机对话及其历史。仅主动加入的对话共享，普通私人对话不自动同步。

每段对话由创建或加入它的设备运行原生 AI 会话，两端都能发送文字，回复、流式文本和工具记录同步显示。模型、工具和审批使用执行设备原会话配置。本机拥有的对话可打开完整会话使用原有附件及权限界面。

记录在两端持久保存。断线后可查看已收记录，恢复后补齐；尚未开始传输的消息排队发送。发送结果不明的消息需要核对结果，不自动重放，避免重复调用模型或执行工具。停止共享保留原生会话，已收到的另一端缓存无法远程撤回。

## 聊天 Factory 接入与前端连接耗尽（0.1.19）

用户反馈 0.1.18 仍无法输入、选择模型或点加号，手机删除仍卡在“正在保存”。真实电脑前端复现了联动会话内的工作区引导以及禁用的模型、附件按钮。确认 0.1.17 的测试使用了错误的普通插槽假体：conversation.content 是 registerFactory 定义，entriesOfSlot 返回空数组，因此对该键包装普通插槽不会影响实际聊天页面。现在包装真实 main.conversation 的 renderFactorySlot 调用，给联动会话的 conversation.content 传入 hero=false 与 active 布局，保留原生所有 Session、输入、模型与附件服务，不改变普通会话。
