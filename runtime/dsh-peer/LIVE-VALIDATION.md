# 实机验收：2026-10-11

## 0.1.2 / DSHAN 1.2.2 跨网络复测

上一次切换网络失败时，手机的移动数据实际处于关闭状态，VPN 的虚拟网卡仍被视为活动网络。复测暂时开启移动数据、关闭 Wi-Fi，保留用户原有 VPN；验证前后都检查 `Wifi is disabled`，结束后恢复 Wi-Fi 开启和移动数据关闭。

- 使用现有公网 HTTP FRP 入口，强制加密中继连接成功；手机读取电脑测试文件，电脑调用手机本机 ADB 状态和截图，PNG 附件完整传回电脑。
- 默认 `auto` 模式也通过跨网络复测：WebRTC 未在等待时间内连上时自动切换加密中继，同样完成双向调用和截图传输。
- 另一次默认模式成功建立 WebRTC 直连。当前网络存在用户 VPN，结果表示在该实际网络配置下可连接，不推断所有运营商网络都能直连；受限网络可使用中继。
- 没有使用 TURN，也没有关闭用户 VPN。新增中继走现有 FRP/WebSocket，数据采用 AES-256-GCM 端到端加密；共享工具、权限、取消和断开逻辑沿用原有管线。
- 自动/强制中继、较大图片、认证篡改、反射、重放、断线、配对期限、指定服务器 IP 保留域名等自动测试通过。旧版服务需升级才能提供加密中继。

以下为 0.1.1 的历史验收记录；其中跨网络失败已由上面的复测更新，其余工具限制仍适用。

手机：OPPO PKQ110、Android 16；桌面：Windows、DeepSeek Harness 0.2.0-rc.2；手机内核 0.1.7-rc.2。使用用户配置的 HTTP FRP 信令入口，两端显式允许 HTTP 信令。没有配置 STUN/TURN。
