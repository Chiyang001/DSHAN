# 实机验收：2026-10-11

## 通过

- 配对、连接状态、两端共享工具目录及双向调用。实际数据使用 WebRTC ICE/DTLS/SCTP，同 Wi-Fi 网络连接成功。
- 电脑调用手机本机 ADB：状态、shell（实际 UID 2000）、显示屏列表、选择主屏、截图、屏幕分析、启动设置、滑动、按键、点击。截图以 PNG 图片附件传回电脑；点击在临时测试输入界面执行。
- 电脑向手机临时输入框输入 `P2P 输入验证 hello 123`；读取输入框实际内容确认完全一致。
- 手机调用电脑文件创建、读取、修改、文件查找、文本搜索、PowerShell 及依赖路径工具；写入仅发生在临时验收目录。
- 未共享工具、递归 peer 工具调用被拒绝；桌面本机权限 guard 拒绝远端终端请求；断开连接后远端无法继续调用。
- 插件 9 项自动测试通过，包括真实 Node WebRTC 通道、附件分片、认证、权限、断线及握手乱序/重传；Android APK 编译成功。
